# Verbatim event text — King of Dragon Pass & Six Ages

Raw source material for prose-craft study. All prose below is quoted verbatim from the
community wikis' transcriptions of in-game event text. Wiki markup (links, bold/italic,
image tags) has been stripped; **no wording has been changed**.

Angle-bracket slots (`<Name>`, `<Hostile Clan>`, `<treasure>`, `<several>`, and `<a/b/c>`
alternation lists) are the games' own engine-filled variables, reproduced exactly as the
wiki records them.

Lines marked `_[wiki context: ...]_` are the wiki editor's own framing sentence, kept only so
you can tell which choice an outcome belongs to. They are NOT game text. Everything inside a
blockquote IS game text.

Where a page carries several event variants (clan version vs tribe version, first event vs
follow-up), each is given its own `**Situation — <section name>:**` heading.
