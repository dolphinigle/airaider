## Context

D-0026 locked autobattles plus pure coin-flip skill checks. Once the campaign moved to Darkest Dungeon's shape (D-0052: one quest a week, multi-battle quests) and combat followed it (D-0041), the designer moved fights to manual play.

## Decision

The designer's words: "in this case i think you want initially combat to be manual by players. LATER there may be quests that disable manual fights forcing you to adopt tactics."

Restated in full (this replaces D-0026):
- A quest resolves through **fights** and **skill checks**.
- **Fights are played by hand** by default: on each merc's turn the player picks the ability and the target.
- **Some later quests disable manual play.** Their fights run on the mercs' **tactics** (D-0030), so the player has to set tactics up.
- **Skill checks are unchanged:** a pure coin flip of the merc's pool against a threshold (D-0013).

## Consequences

- Turn by turn, choices come before every flip ("rolls that pay off a player decision", findings).
- Tactics become a later layer for mastery. The S1–S4 priority order matters only in fights run on tactics.
- Fights must be playable as text: a menu of abilities and targets (text-UI parity).
- E-0003's autobattle findings now apply to fights run on tactics.
