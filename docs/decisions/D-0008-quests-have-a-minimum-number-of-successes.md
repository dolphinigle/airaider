## Context

In E-0001 run 2 Claude used a placeholder rule (two lost tests fail the quest). The designer replaced it.

## Decision

The designer's words: "yes quest have a 'minimum success', harder = need success in more."

- A quest is a sequence of coin tests (see E-0001 run 2) and states a **minimum number of successes**.
- Harder quests need more successes.

## Consequences

- The quest card shows the minimum next to the tests, so the player can judge the odds before assigning.
- Open: whether the quest stops early once the minimum is out of reach, and what failing costs.
