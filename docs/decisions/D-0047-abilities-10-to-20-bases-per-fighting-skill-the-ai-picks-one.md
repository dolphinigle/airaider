## Context

D-0033 rolled one new ability per level up from about 5 bases per skill. Under D-0046 fewer skills fight, so a merc with one fighting skill would run out of bases by about Lv 4.

## Decision

The designer's words: "there should be about 10-20 base abilities for the fighting skills. ai gets offered a few random ones then they pick and rename it to fit the theme."

Restated in full (this replaces D-0033):
- Each fighting skill has **about 10 to 20 base abilities**.
- **Every level up, the merc gains one new ability**, with modifiers by star (D-0027):
  - The engine deals the AI **a few random bases**. They come from the merc's fighting skills, and they fit the merc's weapon (D-0045). They are never a base the merc already knows.
  - The AI **picks one that fits the merc's theme** and **renames it**.
  - **Never the same base twice** (from D-0033).
- A merc **equips four** abilities (from D-0033).

## Consequences

- One fighting skill now covers a whole career (about 13 abilities by Lv 12).
- A merc with no fighting skill still gets no abilities (D-0046, open).
- **Content:** about 16 fighting skills × 10–20 bases comes to about 160–320 base abilities.
- **E-0003 lessons this leans on:**
  - The AI picks from engine-dealt options and never makes mechanics, because AI-made mechanics drifted.
  - Dealing a few options spread the picks out, where free picks piled on raw power.
- **Claude's suggestions:**
  - Show the base next to the AI name ("Bolt Storm · Volley"), so players learn what each base does (E-0003: unique-per-merc skills stop the player learning them).
  - Deal 3 candidates.
