## Context

D-0050 left open whether generic bases ("Smash", "Kick") appear after the first ability.

## Decision

The designer answered "yes ofc" to Claude's question.

- **Generic bases can be among the bases dealt on any level up, but rarely.** This keeps civilians and mercs built on minor skills from running out of new abilities.
