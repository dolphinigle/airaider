## Context

D-0049 gave every merc a 0 cooldown attack as their first ability. Claude proposed it sit in a fixed fifth slot outside S1–S4. The designer ruled against that.

## Decision

The designer's words: "every merc gets a 0 cooldown 'attack' skill as their first skill, always" · "nah it should just be a normal ability. Most skills should have one, like Light Weapon have 'Double attack'. as fallback, there are several 'generic' skills like 'Smash' or 'Kick' that everyone can get".

Restated in full (this replaces D-0049):
- **A merc's first ability is always a 0 cooldown attack.**
- **It is a normal ability.** It takes an equipped slot like any other, is named by the AI and rolls modifiers.
- **Most skills have a 0 cooldown attack among their bases** (Light Weapons: "Double Attack").
- **The fallback is generic attacks** that any merc can get ("Smash", "Kick"). A merc whose skills have no 0 cooldown attack, such as a civilian, gets one of these.

## Open

- Whether generic bases can also be dealt on later level ups (Claude: yes, rarely; this also keeps civilians' pools from running dry).
