## Context

D-0107 set five races with Claude's working stat shifts (catfolk LUK + / CON −).

## Decision

The designer, 2026-10-23: "add orc. +STR. catfolk should be CHA."

Restated in full (replaces D-0107):
- **Six races:** wolfkin, catfolk, elf, dragonkin, **orc**, human.
- **Humans come in four peoples:** northerner, western, eastern, southern, roughly Scandinavian, European, Japanese and African in look and naming (Claude's reading of the order).
- **Stat shifts** (D-0106, + / −): **orc STR +**, **catfolk CHA +** (designer); the rest Claude's working: orc CHA −, catfolk CON −, wolfkin DEX / INT, elf INT / CON, dragonkin CON / DEX.
- Claude's working calls kept from D-0107: human peoples are flavor only and share the human's random +1 / −1 (fixed shifts on real-world-flavored peoples would read as stereotypes); Beast Blood for wolfkin and catfolk, Ancient Blood for dragonkin, both also for shapeshifters.

## Consequences

- Each race's − lands on a different stat except CON (catfolk, elf).
