# Decisions

One decision per file: `D-NNNN-slug.md` ([template](_template.md)). Once accepted, a record is immutable. To change a decision, write a new record with `supersedes: [D-NNNN]`, and set `superseded-by` on the old one (the only edit an accepted record ever gets). Proposed records are the open questions for the designer, and NOW.md lists them.

New record: `node tools/rec.mjs decision "Title"`. The table below is generated by `node tools/rec.mjs index`, so don't edit it by hand.
