## Context

D-0047 has the AI rename each base ability. Claude suggested showing the base next to the AI name ("Bolt Storm · Volley"), because E-0003 found that unique per-merc names stop the player learning what a skill does.

## Decision

The designer's words: "nah dont put the base name, its more exciting for player".

- The player sees **only the AI's name** for an ability, plus what it does: numbers, ranks, cooldown and effects.
- The base is engine-only.

## Consequences

- Each ability's description must say plainly what it does, since no shared base name teaches it.
- This rules out Claude's suggestion in D-0047.
