# RPG skill lists: D&D and its video-game cousins

The standard skill lists of D&D-family games, mapped onto our core skills (D-0021), so no common adventuring action is left without a home. Compiled 2026-10-21 from the D&D 5e SRD 5.1 (also used by Baldur's Gate 3), the Pathfinder 2e Core Rulebook, Pathfinder: Kingmaker / Wrath of the Righteous, Pillars of Eternity II and Divinity: Original Sin 2.

## What the check found

- **The one real gap: perception.** Perception, Insight and Investigation (noticing, reading people, searching) had no home. Spotting an ambush is one of the most common quest moments, so it became its own core skill, **Awareness**.
- Everything else folds into an existing core. Our list adds what D&D lacks as skills: Melee, Ranged, Defense, Tracking, Leadership, Craft.
- Skipped on purpose: luck skills (DOS2's Lucky Charm) and pure magic schools. Luck is the coins themselves.
