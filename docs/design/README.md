# Design (the living spec)

The current truth about how prototype v4 works: one file per system (`squad.md`, `base.md`, `missions.md`, …). The code is built from these pages.

Rules:
- Every rule cites the decision behind it, like `(D-0007)`. A rule with no decision behind it is a proposal and goes to [NOW.md](../NOW.md) instead.
- Rewrite freely to keep pages current and readable. Never keep superseded text here. The decision records hold the history.
- When a decision is accepted, update the page it touches in the same commit.

_Empty until the first v4 decisions are accepted._
