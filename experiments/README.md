# Experiments

Every test lives here, one folder each: `E-NNNN-slug/`. That covers simulated play sessions, real playtests, prompt labs, judge rounds and research sweeps.

```
E-0001-first-game-sim/
  README.md      the record: question, setup, result, verdict (frontmatter: status, type, verdict, decisions)
  *.mjs *.ts     the scripts that ran it, so it can be rerun
  prompts/       prompts and inputs, verbatim
  samples/       curated output worth keeping (committed)
  raw/           bulk output (gitignored, local only)
```

Rules:
- Write the **Question** before running. Fill in **Result** and **Verdict** when done, and set `status: done`.
- Once done, a record is append-only: add a dated note at the bottom rather than rewriting the result.
- An experiment never changes the design directly. A verdict that should change the game proposes a decision (`docs/decisions/`).
- A blind judge tallies against the key file in the folder (`key.json`), never against the labels it was shown.

New record: `node tools/rec.mjs experiment "slug title"`. The table below is generated by `node tools/rec.mjs index`.
