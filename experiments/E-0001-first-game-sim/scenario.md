# E-0001 scenario: Atlas and the road

The fixed test case for trying combat substitutes. Every candidate is played on this same setup so they can be compared.

## Merc
**Atlas**, wolfkin. Strong, smart, gruff, good with swords.

## Quest
**Clear the Road**: "Slay the bandits on the road and make it safe again."
Placeholder numbers used in play so far: reward 40 crowns, 2 days, danger ●●○.

## Rules so far
- The word is **quest** (designer, 2026-10-19).
- One merc per quest for now.
- Goal: find a fun substitute for combat (the "like turn based, whatever" slot). Brainstorm, then try each one live on this scenario.
